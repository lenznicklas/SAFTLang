# SAFTLang
`Static And Fully Typed`

## Types
`bool`
`int`
`string`
`void`
`error`

## (Current) Syntax

### Variable Declaration

`let x = 1` ==> int

`let s = "Hello World"` ==> string

`let b1 = 4 < 9` => bool

`let b2 = s < 1` ==> error

### If/Else

```
if x > 10 {
  foo()
} else {
  foo2()
}
```
